# 🚀 VPN Live Dev — Сервис приватного VPN нового поколения

> **Доменное имя:** [http://vpn.live-dev.by](http://vpn.live-dev.by)  
> **Целевая аудитория:** РФ и РБ  
> **Протокол:** VLESS XTLS Reality (Vision) через Xray-core / 3X-UI  
> **Клиенты:** **INCY** (рекомендуемый 1-click), Happ, Hiddify, браузерный PAC-прокси

---

## ⚡ Особенности и преимущества сервиса

1. **Неблокируемый протокол VLESS Reality:**
   * Полная маскировка под разрешенный HTTPS трафик (маскировка под легитимный SNI `www.microsoft.com:443`).
   * Не определяется ТСПУ (РКН) в России и DPI-фильтрами в Беларуси.
2. **🛡️ Умный «Белый список РФ» (Smart Direct Routing):**
   * При включенном тумблере все сервисы РФ и РБ (**Госуслуги, Сбербанк, Т-Банк, Яндекс, ВТБ, Кинопоиск, Ozon, Wildberries, Avito**) работают **напрямую на полной скорости и без блокировок**.
   * Заблокированные сайты (**YouTube, Instagram, ChatGPT, Twitter/X, запрещенные СМИ**) автоматически идут через защищенный VPN-туннель.
3. **🌐 Подключение без скачивания приложений:**
   * Автоматическая генерация PAC-скрипта (Proxy Auto-Config).
   * Пользователь может просто вставить ссылку в настройки macOS, Windows, iOS или браузера и пользоваться без установки сторонних программ.
4. **🎨 Премиальный дизайн и анимация (Senior UX):**
   * Глубокая темная тема (Obsidian & Emerald Neon), интерактивная 60fps фоновая канвас-анимация.
   * Удобный flow: логин, пароль с переключателем видимости, проверка дубликатов email, восстановление пароля по ссылке на почту в 1 клик.
5. **🧩 Полностью раздельные Docker-контейнеры:**
   * `web` — Сайт, Личный кабинет, REST API, Django Admin.
   * `miniapp` — Автономный Telegram Mini App (работает на независимом веб-сервере Nginx).
   * `bot` — Telegram-бот на `aiogram 3.x` с поддержкой WebApp, реферальной системы и выдачи ключей.
   * Любой контейнер можно пересобирать и перезапускать независимо:  
     `docker compose restart bot`  
     `docker compose restart miniapp`  
     `docker compose restart web`

## 🖥️ Рекомендации по хостингу и серверу (замена ishosting.io)

### Почему `ishosting.io` не подходит для масштабирования:
На `ishosting.io` каналы обычно ограничены 100–200 Мбит/с или имеют ежемесячный лимит трафика в 1–2 ТБ. При подключении 15–30 пользователей, смотрящих YouTube в 4K, лимит быстро исчерпывается, скорость падает до непригодной.

### Рекомендуемые хостинги с безлимитным каналом 1 Гбит/с и чистыми IP:

1. **Aeza International (Нидерланды / Швеция / Австрия / Германия):**
   * **Канал:** Честный **1 Гбит/с Unmetered** (безлимитный трафик).
   * **Процессоры:** AMD Ryzen 9 (минимальные задержки при шифровании).
   * **Маршруты:** Прямые каналы через RETN до Москвы и Минска (пинг 35–45 мс).
   * **Оплата:** Российские карты (МИР, СБП), Криптовалюта.
   * **Цена:** ~4.9€ / мес.
2. **PQ.Hosting (Нидерланды / Финляндия):**
   * **Канал:** Безлимитный 1 Гбит/с трафик.
   * **Оплата:** Карты РФ, зарубежные карты, крипта.
   * **Цена:** от 4.5€ / мес.
3. **Friendhosting / JustHost (Нидерланды):**
   * Проверенные бюджетные европейские локации с чистыми IP.

> ⚠️ **Важно:** Перед покупкой или прикреплением IP проверьте адрес через [Cheburcheck.ru](https://cheburcheck.ru). Если адрес чистый — на нем VPN будет работать стабильно и без сбоев.

## 🚀 Пошаговое развертывание на сервере

### Шаг 1. Подготовка сервера (VPS)
Подключитесь к VPS по SSH (Debian 12 или Ubuntu 22.04+):
```bash
ssh root@your-server-ip
```

Склонируйте репозиторий и запустите скрипт оптимизации сетевого стека (BBR):
```bash
git clone <URL_РЕПОЗИТОРИЯ> /opt/vpn-live-dev
cd /opt/vpn-live-dev
chmod +x deploy/scripts/setup_vps.sh
./deploy/scripts/setup_vps.sh
```

### Шаг 2. Настройка конфигурации (.env)
Скопируйте шаблон переменных окружения:
```bash
cp .env.example .env
nano .env
```
Укажите:
* `DOMAIN=vpn.live-dev.by`
* `SITE_URL=http://vpn.live-dev.by`
* `BOT_TOKEN=...` (токен вашего бота из @BotFather)
* `BOT_USERNAME=...` (юзернейм бота)
* `EMAIL_HOST_USER` и `EMAIL_HOST_PASSWORD` (для отправки ссылок восстановления)

### Шаг 3. Запуск контейнеров
Запустите все сервисы:
```bash
docker compose up -d --build
```

Проверьте статус контейнеров:
```bash
docker compose ps
```

### Шаг 4. Создание администратора
Создайте суперпользователя для входа в панель управления:
```bash
docker compose exec web python manage.py createsuperuser
```
Панель управления будет доступна по адресу:  
👉 **`http://vpn.live-dev.by/admin/`**

## 📱 Как пользователи подключаются

### Вариант 1: Через приложение INCY (1 клик)
1. Пользователь заходит на сайт или в Telegram-бота.
2. Нажимает кнопку **«⚡ Подключить в 1 клик (INCY)»**.
3. Браузер открывает приложение INCY и автоматически импортирует защищенный ключ и подписку.
4. Доступ открыт!

### Вариант 2: По QR-коду (для ТВ и планшетов)
1. В кабинете или боте нажать **«📱 QR-код»**.
2. Отсканировать камерой в приложении INCY или на Android TV.

### Вариант 3: Без установки приложений (Браузер / PAC)
1. В кабинете нажать **«Инструкция по настройке PAC»**.
2. Вставить ссылку `http://vpn.live-dev.by/vpn/pac/<token>/` в сетевые настройки системы (macOS / Windows / iOS).
