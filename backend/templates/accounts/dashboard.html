Подключение через PAC-скрипт

Позволяет использовать VPN прямо в браузере или системе без сторонних программ:

1. Скопируйте URL скрипта:

2. Вставьте в настройки системы:

  • В macOS: Сеть → Дополнительно → Прокси → Автоконфигурация (PAC)
  • В Windows: Параметры → Сеть и интернет → Прокси → Использовать скрипт
  • В iOS: Wi-Fi → Настройка прокси → Автоматически

2. Роутеры с OpenWrt (Xiaomi, GL.iNet, TP-Link, ASUS)

Установите плагин Passwall, OpenClash или luci-app-xray.

  • В разделе Node Subscribe вставьте ссылку на подписку.
  • Включите режим China / Russia Direct (белые списки включатся автоматически).
